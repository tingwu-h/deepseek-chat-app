# 万象 v1.2.2.2

这次更新让聊天窗口更紧凑，统一弹出菜单的圆角样式，并修复设置分类与保存提示。

- **底部窗口更紧凑**：减少输入区域上下留白，模型选择继续放在同一个圆角窗口内、文字输入区下方。
- **统一圆角菜单**：附件选择、模型切换、右上角对话操作和历史会话菜单使用一致的圆角、底色和阴影；设置下拉框、对话框和底部面板同步调整。
- **紧凑模型列表**：模型选择弹窗限制高度，支持上下滑动；每个模型使用独立圆角卡片展示名称和擅长标签，当前模型以主题色边框和勾选标记突出。修订继续使用 v1.2.2.2，替换同名安装包。
- **修复分类遮挡**：设置分类展开后为首个选项留出间距，将标题点击效果限制在标题区域，避免覆盖内容。
- **保存提示自动消失**：成功保存后短暂显示提示；底部只在有修改或正在保存时显示状态。
- **背景衔接更自然**：自定义颜色或图片铺到整个聊天页，顶部、底部输入区域及底部安全区保留明显底色，仅透出少量背景，兼顾图标和文字的可读性。浅色与深色主题分别使用对应底色。

Android 版本 `1.2.2.2`，构建号 `15`；Dart 工程版本 `1.2.2+15`。沿用原包名和签名，签名文件保持原位置。

静态分析、71 项回归测试及 Release APK 构建通过，签名一致性已校验。测试覆盖圆角菜单、模型列表上下滑动与首尾选择、设置保存提示消失、分类展开间距、自定义背景底色和键盘弹出布局，并生成 Flutter 布局预览。当前未连接安卓设备，真机安装与交互效果尚未验证。
