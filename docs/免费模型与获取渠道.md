# 免费模型与获取渠道

在万象中打开 **设置 → 模型与服务 → 选择免费模型**。选中后会自动填写服务商和模型，再点击 **获取 API Key** 到对应官方平台申请。复制 Key，回到万象粘贴并保存即可。测试连接会发出一次真实请求，并占用相应额度。

| 选项 | 适用方向 | 获取 Key | 官方模型与额度说明 |
| --- | --- | --- | --- |
| OpenRouter 免费自动选模 `openrouter/free` | 日常问答；平台自动选择可用免费模型 | [OpenRouter API Keys](https://openrouter.ai/settings/keys) | [免费路由说明](https://openrouter.ai/openrouter/free) |
| Qwen 3.8 27B 免费变体 `qwen/qwen3.8-27b:free` | 编程、图片理解 | [OpenRouter API Keys](https://openrouter.ai/settings/keys) | [模型与供应情况](https://openrouter.ai/qwen/qwen3.8-27b:free) |
| Gemini 2.5 Flash-Lite `gemini-2.5-flash-lite` | 快速问答、图片理解 | [Google AI Studio API Key](https://aistudio.google.com/apikey) | [官方价格与免费层](https://ai.google.dev/gemini-api/docs/pricing#gemini-2.5-flash-lite) |

## 申请与使用

1. 打开对应官方 Key 页面，注册或登录账号。
2. 根据平台要求创建项目或 API Key；只为该服务商使用对应的 Key。
3. 复制 Key，在万象里粘贴，点击保存。
4. 可点击测试连接验证配置；连接成功后回到聊天页开始使用。

## 免费的范围

- **OpenRouter**：这两个模型 ID 在核对时的输入、输出价格均为 0；免费请求有频率或每日限额，模型供应情况可能变化。自动选模的实际模型和能力也会变化。官方实时目录：[Models API](https://openrouter.ai/api/v1/models)。
- **Google**：Flash-Lite 提供免费层，付费层另行计费。额度、地区和账号资格由 Google 管理；免费层内容可能用于改进其产品，提交内容前请阅读官方政策。
- 万象不会内置或提供共享 Key，不会在免费请求失败时自动切换到付费模型。不支持的地区、额度耗尽或暂时不可用时，请依据错误提示到官方平台处理。
- 自定义接口的费用由该接口运营方决定，不能因为模型名称相同就认定免费。模型用途标签是参考，不承诺每次回答效果。
- 模型、价格与获取页面在 **2026-10-03** 核对；未用真实账号进行在线请求验证。
