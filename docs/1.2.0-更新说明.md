# 万象 v1.2.0

## 版本与兼容

- 应用从「DeepSeek 助手」更名为「万象」，Android 桌面显示名、应用内品牌与 Logo 同步更新。
- 版本号 `1.2.0+11`；包名继续使用 `com.example.deepseek_chat`。
- 签名文件保持用户原位置，不移动、不更换；延续旧版证书。
- 仓库由用户更名为 `tingwu-h/wanxiang-chat-app`，沿用原仓库提交历史。

## 功能

- DeepSeek、OpenAI、Kimi、Qwen、Anthropic、Google、xAI、GLM 八家预置，加自定义服务商入口。
- 每个服务商分别保存密钥、接口地址、模型与协议；密钥只进入 Android 加密存储。
- 支持 OpenAI 兼容 Chat Completions、OpenAI Responses、Anthropic Messages、Google Gemini。
- 支持流式文本、实际返回的思考片段、取消生成、连接测试、图片与纯文本附件。
- 自定义模型可以明确设置图片能力，模型 ID 与账号可用性以服务商为准。
- 会话保存服务商与模型，重启或重新选择会话时恢复。
- 旧版密钥、普通设置与聊天记录可迁移；保留原存储键、平台通道和应用 ID。

## 桌面端

本版只开发 Android。通过 ChatService、ApiProtocol、PlatformBackend 分离聊天协议与平台服务，预留后续桌面端接入。非 Android 密钥目前只保存在内存，不宣称桌面端已完成。

## 验证与限制

- 测试使用模拟接口，不使用个人真实 API Key，不产生 API 用量。
- 没有八家平台的真实密钥，因此未验证账号权限、余额、区域访问、当前模型可用性及线上回复质量。
- 图片来源是用户提供的品牌合成图，图标从独立图标区域提取，并生成 Android 多尺寸、自适应图标。
- 不包含联网搜索、工具执行、语音或 PDF / Word 解析。
- 包名、版本号与证书可通过 APK 工具校验；实际手机覆盖安装和旧数据保留仍需真机验证。
