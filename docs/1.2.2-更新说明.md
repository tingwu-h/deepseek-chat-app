# 万象 v1.2.2

本次更新让聊天界面更紧凑，也让你可以按自己的习惯调整语言和背景。

## 更新内容

- 启动画面统一使用万象图标，补齐 Android 12 及以上系统的启动主题。
- 模型选择移至单行顶栏；新建对话、清空当前对话统一放进右上角菜单。
- 外观设置新增 **简体中文 / 繁體中文 / English**，界面和系统文字选择菜单跟随切换。
- 可选择聊天背景颜色、输入自定义颜色，或从相册上传背景图片。
- 聊天图片与背景图片共用编辑器：拖动和双指缩放、裁剪比例、2× / 4× 放大输出。
- 超过 5 MB 的图片输出自动压缩；处理副本保存在应用目录，不修改相册原图。

## 使用方式

从左侧抽屉进入 **设置 → 外观设置**，选择语言、颜色或上传背景图片，修改立即生效。

选择图片后，在预览中调整裁剪范围，点击右上角「使用」。退出编辑不会使用该图片。图片最终最长边限制为 2048 像素；动画图片按首帧保存为静态图片。放大能改变输出尺寸，不能恢复原图没有的细节。背景图片只用于本地显示，不会自动发送给模型。
