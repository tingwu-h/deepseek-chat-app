# 万象 v1.2.2.1

本次更新调整聊天布局，修复语言选择体验，并为服务商增加参考标签。

- **会话名称回到顶部**：显示当前会话名称，重命名后同步更新；长标题省略显示，可长按查看完整标题。
- **模型选择收进底部圆角窗口**：放在文字输入区下方，采用更小的文字和图标，保留方便点击的区域；只列出当前服务商的模型及其保存的自定义模型。
- **外层窗口加高**：文字输入框保持原来的单行起始高度；外层圆角窗口同时容纳输入区与模型选择，键盘弹出时限制文字区增长。
- **语言选择更顺畅**：外观设置采用统一列表行，点击后打开底部选择面板，支持简体中文、繁體中文、English；面板关闭后生效。
- **修复外观重叠**：「主题立即生效」提示与语言设置增加独立间距和分隔线。
- **服务商参考标签**：在服务商选项和当前服务商下方显示编程、推理、写作、长文、图片理解等方向，具体模型的标签继续保留。标签是选择参考，不代表所有模型具备相同能力。
